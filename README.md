# コース戦略（MVP）

ラウンド中にスマホで「どの番手で、どこを狙うと、どこに落ちるか」を確率楕円で表示する個人用PWA。
対象コース: `courses/index.json` に列挙（木曽駒高原カントリー・西仙台カントリークラブ）。設定画面で切替、ホール登録・画面状態はコースごとに保存

## 構成

- ビルド不要の静的サイト（HTML + ES Modules）。サーバー・DB不要、費用0円
- 地図: 国土地理院 シームレス空中写真 または Esri World Imagery（設定で切替。MapLibre GL JS で表示、回転可）
- 標高: 国土地理院 標高タイル（1mレーザ → 5m → 10m の順にフォールバック）。木曽駒高原は全域1mメッシュ
- データ保存: 端末の localStorage（ショットCSV・設定・ホール位置）
- オフライン: Service Worker。設定画面の「このコースを端末に保存」で航空写真・標高タイル約400枚を事前キャッシュ

| ファイル | 役割 |
|---|---|
| `js/model.js` | CSV解析・番手別統計・モンテカルロ着弾シミュレーション（風・高低差補正）・確率範囲 |
| `js/dem.js` | 標高タイルのデコードと標高取得 |
| `js/contour.js` | 点群から確率範囲の輪郭を作成（密度格子＋マーチングスクエア） |
| `js/geo.js` | 緯度経度⇔ローカル平面、タイル計算 |
| `js/app.js` | 画面・地図・操作 |
| `sw.js` | オフラインキャッシュ |

## ラウンド中の位置合わせ

- GPS: 最大8秒測位を続け、誤差の小さい測位ほど重くして平均。誤差範囲を青い円で表示
- 距離リング: 選択中ホールのグリーンセンターから10刻みの同心円（50刻みに数字）。エッジ表示のカート向けに基準をずらせる
- 残り距離で補正: カートナビ・距離杭の残り距離を入力すると、グリーンから見た方向は保ったまま距離を合わせる
- 2グリーン: ホール登録時にA/B両方を登録し、上部の「AG/BG」で切替（`courses/*.json` の `greens: 2`）
- 予報の風: Open-Meteo の現在値（地上10m）を取得。方位は絶対値で持ち、打つ方向に合わせて自動換算

## 計算モデル

1. 番手ごとに「キャリー × 左右ブレ」の実ショットを保持
2. カーネル密度推定で2000球をサンプリング: 実ショットを1球ランダムに選び、小さな揺らぎ（Silverman則のバンド幅）を加える。分布の形を仮定しないので、片寄ったミスや大ミスの頻度がそのまま出る
   - 直近重視: 番手ごとに最新の練習日から「半減期」日さかのぼるごとに抽出確率を半分にする（既定60日、設定で変更・無効化可）。平均・ばらつきも同じ重みで計算
3. 補正を適用
   - 空気密度（標高・気温）: 練習データは練習日の条件（`data/sessions.json` の練習場標高・気温）で標準大気（海抜0m・15℃）に換算して保持し、コースでは打つ位置の標高（国土地理院）とラウンド中の気温で戻す。係数は「標高1000mでキャリー+4%」（約1.2%/1000ft、設定で変更可）から逆算し、気温にも同じ密度関係を適用（10℃で約+1.2%）。ラウンド中の気温は風パネルで入力、または Open-Meteo から現在値を取得
   - 飛距離補正（レンジボール→実球）、ブレ拡大率（マット→芝・実戦）
   - 風: 向かい風 1.4%/m/s 減、追い風 1.0%/m/s 増、横風はキャリーに比例して横流れ
   - 高低差: 着弾点ごとの標高差 ÷ tan(落下角) だけキャリーを補正（落下角は 1W 38°〜ウェッジ 52°）
4. 点群の密度から 50% / 80% / 95% の最高密度領域を描画（楕円を仮定しないので、離れたミスの塊は別の島として表示）
5. 「実質距離」= 狙い点までの距離を高低差・風で平地無風換算した値。平均キャリーが最も近い番手を「おすすめ」表示

係数はすべて設定画面から変更可能。

## ショットデータ（CSV）

```
club,carry,offline,landing
8-iron,145,L 14,47
8-iron,142,R 12,50
```

- ヘッダ名（Club / Carry / Offline / Landing、クラブ / キャリー / 左右 / 落下角 など）で列を自動判別
- 扱うのはキャリーのみ（ランはライで大きく変わるため使わない）
- landing（落下角）があれば高低差補正に実測値を使う。なければ番手別の目安値
- 取込は番手単位の置き換え（取り込んだ番手だけ更新、他は保持）
- 更新手順: TOPTRACERアプリのスクショ → Claudeアプリ（設定画面の「Claude用プロンプトをコピー」）→ CSVを貼り付けて取込
- 番手名は `Driver`・`7 Iron`・`4 Hybrid`・`Pitching Wedge`・`7番アイアン` なども正規化
- offline は「右+ / 左−」または「12 L」「8 R」
- 番手ごとに20球以上推奨
- `data/shots.csv` が同梱データ（全端末共通の基準データ。列: date, club, session, shot, carry, offline, landing）。無い場合は `sample/shots_sample.csv`（架空データ）
- 端末で取り込んだ番手は同梱データより優先（番手単位）
- ウェッジはロフト角で表示（GW=48°, SW=52°, LW=56°。設定画面で変更可）

## ローカル起動

```bash
python -m http.server 8765
```

http://localhost:8765 を開く。スマホで GPS・オフライン機能を使うには HTTPS 配信（GitHub Pages / Cloudflare Pages 等）が必要。
